DUO DESKTOP - BETA WINDOWS

1. Descomprime todo el ZIP en una carpeta.
2. Haz doble clic en "Iniciar Duo Desktop.cmd".
3. Inicia sesion con tu cuenta de prueba.

No muevas solamente el .exe: las carpetas app y service forman parte del programa.

Funciones locales opcionales:
- Git debe estar instalado para worktrees/commits.
- GitHub CLI (gh) para crear/sincronizar pull requests.
- Codex, Claude Code o Gemini CLI solo si quieres probar esos agentes.

ChatGPT y Grok usan el navegador integrado y no necesitan un CLI local.
